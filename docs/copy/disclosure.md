# Affiliate disclosure

Some links from HostBench to hosting platforms and related tools are affiliate links. If you follow one and sign up or buy, we may earn a commission.

Affiliate status has no effect on measurements or rankings. Tests run on an automated schedule, and the ranked tables are sorted by measured results alone. Hosts with no affiliate program are measured and ranked the same way as hosts with one.

Some hosts and tools also pay for placements labelled "Featured" or "Sponsored". These are always marked and always sit outside the ranked table.
