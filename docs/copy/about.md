# About

Most hosting benchmarks are blog posts. Someone deploys a test page to five platforms, runs a few requests from their laptop, and publishes a chart. The chart is accurate for that afternoon, from that city. A year later it is still the top search result, and the platforms have changed their networks twice since.

We could not find anyone measuring these platforms continuously, from several regions, with the method published. So we built HostBench to do it.

Every hour, probes in 8 regions request a small static page on each platform and record how long each stage of the request took. The results roll up into the tables and charts on this site and into a monthly report. The method is described in full on the [methodology page](/methodology), and the code is public at [REPO_URL].

## Who runs it

## How it is funded

Some outbound links to hosts are affiliate links. If you sign up through one, we may earn a commission. Some hosts also pay for placements marked "Featured" or "Sponsored". Those placements sit outside the ranked table.

Money does not touch the measurements. Results are collected and ranked by an automated pipeline, and whether a host pays us has no effect on where it appears in a ranking. The full terms are on the [disclosure page](/disclosure).
